# MSPGC Demo

Companion org for **Stop Emailing PowerShell Scripts: Source Control for MSP Teams**, an MSPGeekcon 2027 session.

The talk follows one PowerShell script from a file on someone's desktop to a reviewed, tested and automatically released asset. Everything shown on stage lives here, so you can look around, fork it and copy whatever is useful.

## Start here

| Repo | What it shows |
| --- | --- |
| [msp-scripts](https://github.com/MSPGC-Demo/msp-scripts) | The running example: a script, its tests, checks on every pull request and versioned releases |
| [.github](https://github.com/MSPGC-Demo/.github) | Org-wide defaults: issue forms, a PR template, policies, workflow templates and shared workflows |
